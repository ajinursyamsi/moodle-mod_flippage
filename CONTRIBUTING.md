# Contributing

Contributions are welcome through GitHub issues and pull requests.

Before submitting a change:

- Keep changes focused and easy to review.
- Follow Moodle coding style.
- Do not add external runtime CDN dependencies.
- Include a short explanation of the problem and the behaviour after the change.
- Run PHP lint and, where possible, Moodle plugin CI checks.

Security-sensitive issues should be reported privately using the process in `SECURITY.md`.
